# 📖 القرآن الكريم — MC88

مصحف رقمي هادئ للقراءة برواية حفص عن عاصم، مبني بواجهة بسيطة وخفيفة لتناسب الهاتف والحاسوب، وبدون أي إعلانات. يعتمد المشروع على جلب البيانات برمجياً لتقديم تجربة قراءة سلسة وسريعة.

## ✨ المميزات الأساسية
* 📖 **قراءة مريحة:** واجهة نظيفة مع حفظ تلقائي محلي لآخر سورة تمت قراءتها للرجوع إليها لاحقاً.
* 🔍 **البحث السريع:** محرك بحث مدمج للبحث بكلمة أو عبارة محددة داخل النص القرآني بالكامل.
* 🎨 **تخصيص المظهر:** 4 قوالب ألوان مريحة للعين لتناسب بيئات الإضاءة المختلفة (المدينة، زمرد، ليلي، ورقي).
* 🔠 **التحكم بالخط:** إمكانية تكبير وتصغير حجم الخط (تُحفظ التفضيلات تلقائياً).
* 📿 **الوصول للأذكار:** زر مخصص للانتقال المباشر إلى موقع الأذكار التابع للمشروع.

## 🛠️ التقنيات المستخدمة
* 💻 **الواجهة الأمامية:** HTML, CSS, JavaScript (مدمجة في ملف واحد لسهولة النقل).
* 📡 **البيانات (API):** جلب النص القرآني ديناميكياً بصيغة JSON عبر حزمة `quran-json` (باستخدام jsDelivr).
* 💾 **التخزين المحلي:** الاعتماد على `localStorage` لحفظ المظهر، حجم الخط، ورقم السورة المرجعية.

## 🚀 التشغيل والاستخدام
المشروع يعمل بالكامل من جهة العميل (Client-side) ولا يحتاج إلى خادم معقد.
1. قم بتنزيل ملف `index.html`.
2. افتح الملف باستخدام أي متصفح ويب حديث (يتطلب اتصالاً بالإنترنت في المرة الأولى لجلب بيانات السور).
3. يمكن استضافة الملف مجاناً وبسهولة عبر منصات مثل GitHub Pages.

* 📖 **بخصوص الرواية المعتمدة:** قد تلاحظ أن اسم الموقع أو الرابط يحتوي على كلمة "ورش" بينما النسخة المتوفرة حالياً هي برواية "حفص عن عاصم". السبب هو أنني واجهت صعوبة في إيجاد واجهة برمجية (API) مناسبة لرواية ورش أثناء بناء المشروع.
* 🔗 **سبب عدم تغيير الاسم:** لم أقم بتغيير اسم الموقع حتى الآن نظراً لارتباطه حالياً بمشروع آخر خاص بي يحمل اسم **All In**، ولكن سيتم تحديث الاسم وتصحيح هذا الأمر في القريب العاجل إن شاء الله.
